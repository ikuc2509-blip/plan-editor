# Редактор плана места происшествия

Приложение для составления развёрнутого плана помещения при осмотре места происшествия: план пола, развёртка стен, метки обнаруженных объектов, легенда, примечания, штамп. Результат — лист A3 в PDF для печати и подписи.

Учебный проект для семинара по криминалистике. Пример — учебная аудитория (ул. Широкая, 33).

Работает в браузере, без интернета после загрузки и без облака: данные осмотра никуда не отправляются.

## Как запустить у себя

Нужен [Node.js](https://nodejs.org) версии 22 или новее.

```
npm install      # один раз: скачать библиотеки
npm run dev      # запустить; адрес появится в окне, обычно http://localhost:5173
```

## Другие команды

```
npm test         # автотесты расчётов
npm run typecheck  # проверка типов
npm run build    # собрать сайт в папку dist/
```

## Где что лежит

- `src/` — код приложения;
- `examples/` — учебная аудитория и эталонные листы для тестов;
- `prototype/` — исходный прототип и образец оформления листа;
- `docs/decisions.md` — принятые решения;
- `TODO.md` — план работ по этапам.

## Публикация

Сайт публикуется на GitHub Pages автоматически при каждом изменении ветки `main` (`.github/workflows/deploy.yml`). Перед публикацией прогоняются тесты.
